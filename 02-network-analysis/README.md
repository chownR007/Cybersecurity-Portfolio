# Network Traffic Analysis — Wireshark

**Project Type:** SOC / Blue Team  
**Environment:** Controlled Cybersecurity Training Lab  
**Status:** In Progress

## Objective

Analyze network traffic using Wireshark to identify normal and potentially suspicious network activity.

## Scenario

A simulated security investigation requires analysis of a network packet capture to determine what systems communicated, which protocols were used, and whether any unusual activity can be identified.

## Investigation Goals

- Analyze network packets
- Identify communicating hosts
- Identify protocols and services
- Examine DNS traffic
- Analyze HTTP traffic
- Identify suspicious network behavior
- Document findings
- Develop an incident timeline

## Tools

- Wireshark
- Packet Capture (PCAP)
- TCP/IP
- DNS
- HTTP
- Network Analysis
