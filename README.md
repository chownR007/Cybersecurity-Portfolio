🔐 Ethics & Responsible Security

All security testing and exploitation documented in this repository is performed in authorized environments, intentionally vulnerable systems, or security training platforms.

I do not conduct unauthorized testing against systems, networks, accounts, or applications.

The purpose of these projects is education, defensive security, and professional development.
